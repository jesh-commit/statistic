# Statistic

Application de traitement et de normalisation des rapports statistiques Excel pour les postes frontaliers de Sakania et Mokambo.

## Objectif

Importer des fichiers source Excel (`.xlsb`, `.xlsx`, `.xls`), vérifier et mapper les colonnes, prévisualiser les données, puis exporter le rapport normalisé sans modifier le fichier d'origine.

## Statut

Initialisation du projet. Les règles métier détaillées et les calculs seront confirmés avant leur implémentation.
